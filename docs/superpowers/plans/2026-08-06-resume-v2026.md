# Resume v2026 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `/resume` route in the portfolio that prints to a one-page A4 PDF ("print-mode terminal"), plus a portrait-QR asset and an `npx dagas` terminal card.

**Architecture:** Resume content lives as data in `src/data/resume.ts` (curated from `info.ts`). One self-contained Astro page renders it print-first; `@media print`/`@page` CSS makes browser print = final PDF. Node scripts generate the portrait-QR SVG and export the PDF via system Chrome (`playwright-core`, no browser download). The npx card is an independent zero-dep package in `npx-card/`.

**Tech Stack:** Astro 6, Tailwind v4 (theme vars only — resume page uses plain CSS), `qrcode` (matrix only, custom SVG render), `playwright-core` + installed Chrome, Node ≥22.12.

## Global Constraints

- One A4 page. If content overflows, cut content — never shrink type below 8.5pt body.
- Paper palette (site accents are too light on white): paper `#faf9f6`, ink `#16161d`, muted `#5c5c66`, green `#15803d`, teal `#0e7490`. Dark allowed ONLY in the titlebar strip + QR modules.
- JetBrains Mono for structure (headers, labels, dates, tags); Inter for body bullets. Loaded via the same Google Fonts URL the site already uses.
- All PDF text must be real selectable text; section headings keep semantic words ("Experience") with prompt styling done in CSS decoration.
- No phone numbers; email comes from `info.contact.email` (already public on the site).
- No edits to existing site pages/components except none-needed; `info.ts` is read-only input.
- Never `git push` to master; work stays on `worktree-resume-v2026`, PR at the end.

### Task 2: ASCII portrait asset

**Files:**
- Create: `scripts/gen-portrait-ascii.py` (dev tool, committed for reproducibility)
- Create: `src/data/portrait-ascii.txt` (generated, committed)

**Interfaces:**
- Produces: `portrait-ascii.txt` — rigid-grid ASCII (~34×22 chars) of `~/WorkFiles/Resume/myPic.png`, used by Task 3 (page rail) and Task 4 (QR center emblem).

- [ ] **Step 1: Write the generator** (site's proven Pillow recipe: luminance→ramp, threshold drops light bg to spaces, no rstrip):

```python
#!/usr/bin/env python3
"""one-off: myPic.png -> small ASCII portrait (rigid grid, light bg -> spaces)."""
from PIL import Image
import sys

SRC = sys.argv[1] if len(sys.argv) > 1 else '/Users/dagas/WorkFiles/Resume/myPic.png'
OUT = 'src/data/portrait-ascii.txt'
COLS, ROWS = 34, 22          # char-cell aspect ~0.5 compensates in ROWS
RAMP = '@%#*+=-:. '          # dark -> light
THRESHOLD = 235              # luminance above this = background = space

img = Image.open(SRC).convert('L').resize((COLS, ROWS))
px = img.load()
lines = []
for y in range(ROWS):
    row = ''
    for x in range(COLS):
        v = px[x, y]
        row += ' ' if v >= THRESHOLD else RAMP[min(int(v / 256 * len(RAMP)), len(RAMP) - 1)]
    lines.append(row)          # NO rstrip — rigid grid
open(OUT, 'w').write('\n'.join(lines) + '\n')
print(f'wrote {OUT} ({COLS}x{ROWS})')
```

```js
// portrait-QR: QR matrix (EC level H tolerates ~30% damage) with a center
// window holding the ASCII portrait. custom SVG render, resume paper palette.
import QRCode from 'qrcode';
import { readFileSync, writeFileSync, mkdirSync } from 'node:fs';

const URL_TARGET = 'https://dagas-portfolio.vercel.app';
const qr = QRCode.create(URL_TARGET, { errorCorrectionLevel: 'H' });
const n = qr.modules.size;
const data = qr.modules.data;

const CELL = 10;                 // svg units per module
const HOLE = Math.floor(n * 0.36); // center window edge (modules) — < H tolerance
const h0 = Math.floor((n - HOLE) / 2), h1 = h0 + HOLE;

const portrait = readFileSync('src/data/portrait-ascii.txt', 'utf8').split('\n').filter(Boolean);

let cells = '';
for (let y = 0; y < n; y++)
  for (let x = 0; x < n; x++) {
    if (x >= h0 && x < h1 && y >= h0 && y < h1) continue; // carve window
    if (!data[y * n + x]) continue;
    // finder patterns stay square (scanners key on them); data modules rounded
    const finder = (x < 8 && y < 8) || (x >= n - 8 && y < 8) || (x < 8 && y >= n - 8);
    cells += finder
      ? `<rect x="${x * CELL}" y="${y * CELL}" width="${CELL}" height="${CELL}"/>`
      : `<rect x="${x * CELL + 1}" y="${y * CELL + 1}" width="${CELL - 2}" height="${CELL - 2}" rx="2.5"/>`;
  }

const win = HOLE * CELL;
const fs = (win / portrait.length) * 1.34; // fit rows into window height
const text = portrait
  .map((line, i) =>
    `<text x="${h0 * CELL + win / 2}" y="${h0 * CELL + (i + 0.86) * (win / portrait.length)}" font-size="${fs.toFixed(2)}" text-anchor="middle" xml:space="preserve">${line
      .replaceAll('&', '&amp;').replaceAll('<', '&lt;').replaceAll('>', '&gt;')}</text>`)
  .join('');

const size = n * CELL;
const svg = `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 ${size} ${size}" shape-rendering="crispEdges">
<rect width="${size}" height="${size}" fill="#faf9f6"/>
<g fill="#16161d">${cells}</g>
<g fill="#15803d" font-family="JetBrains Mono, ui-monospace, monospace" font-weight="600">${text}</g>
</svg>`;

mkdirSync('public/images', { recursive: true });
writeFileSync('public/images/portrait-qr.svg', svg);
console.log(`portrait-qr.svg: ${n}x${n} modules, window ${HOLE}, target ${URL_TARGET}`);
```

  const L = [];

  r.header.forEach((h) => L.push(`${h.k}: ${h.v}`));
  L.push('', 'EXPERIENCE', '----------');
  r.experience.forEach((e) => {
    L.push(`${e.role} — ${e.company} (${e.where}, ${e.when})`);
    e.bullets.forEach((b) => L.push(`- ${b}`));
    L.push('');
  });
  r.ledger.forEach((l) => L.push(`${l.when}  ${l.what}`));
  L.push('', 'PROJECTS', '--------');
  r.projects.forEach((p) => L.push(`${p.title} [${p.tags.join(', ')}]`, p.blurb, ''));
  L.push('SKILLS', '------');
  Object.entries(r.stack).forEach(([g, i]) => L.push(`${g}: ${i.join(', ')}`));
  L.push('', 'EDUCATION', '---------');
  r.education.forEach((e) => L.push(`${e.when}  ${e.what}`));
  L.push('', 'LANGUAGES', '---------');
  r.languages.forEach((l) => L.push(`${l.k}: ${l.v}`));
  writeFileSync('public/resume.txt', L.join('\n') + '\n');
  console.log('wrote public/resume.txt');
} finally {
  server.kill();
}

line();
